# U2-ejercicio32
# Sistema de Gestión de Descuentos Comerciales

**Objetivo principal:** Desarrollar un sistema modular en Java que permita calcular descuentos comerciales mediante distintas políticas, utilizando abstracción y polimorfismo.

El programa implementa una interfaz `PoliticaDescuento` y tres estrategias concretas: descuento por lealtad, descuento estacional y descuento por volumen. La clase `CalculadoraPrecios` utiliza estas políticas para calcular el ahorro y el precio final de una compra.

**Conceptos aplicados:**
- Interfaces y abstracción.
- Implementación de métodos.
- Polimorfismo.
- Encapsulamiento.
- Desacoplamiento.
- Patrón de diseño Strategy (Estrategia).
